Legacy Codex: Eddie's workflow demonstration for Vaughn
App: https://legacy-codex.vercel.app/
North Star: preserve rich human intent so another intelligence can reconstruct, execute, verify, and continue it.

1. Open the app in Eddie's existing signed-in browser; keep the account/session that already holds his work.
2. In Mission, inspect the existing Primary outcome, finish line, and saved action. Resume that action rather than creating a duplicate.
3. Open Something changed / Project context. Record a real note explaining the larger outcome, current uncertainty, or connection the system should notice. Optionally include a public GitHub blob link to a real text file.
4. Press Review project. This reads the selected mission, related outcomes, linked evidence, commitments/resumption notes, corrections, context notes and up to two explicitly linked repository files.
5. Open Why this? Inspect the proposed bigger picture, evidence-to-action explanation, overlooked connection, self-check, unknowns, and cited excerpts. Ask Vaughn whether the interpretation matches the actual intent.
6. If the recommendation misses the point, use Correct this, record the reason, and review again. Human corrections constrain later reasoning; an AI proposal is still a proposal.
7. Accept a useful next move, explicitly save it only if needed, and verify the same action/note after reload. Show Vaughn from Eddie's session; opening the public app does not give a visitor Eddie's data or owner-only model access.

The original Goose incident and cookbook-to-chef method remain in Codex > Root > North Star and in application model prompts. The two-pass review reconstructs then critiques; it does not autonomously edit or deploy its own code.
